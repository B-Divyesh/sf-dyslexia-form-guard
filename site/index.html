READOUT / FAQ

Before you install

Is this a spelling or grammar checker?

No. It is a conservative final-pass tool for a few common, detectable slips. It does not judge style or claim a sentence is correct.

Does it diagnose or treat dyslexia?

No. Form Guard is a general-purpose review aid informed by a specific workflow. It is not a medical device and makes no claim of medical benefit.

Why does it request access to web pages?

An extension needs page access to read visible form controls after you start a scan and to outline the current field. It excludes password values and does not retain what it reads.
